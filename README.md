Scenario Description

This Dart console application calculates the order receipt details for a fast-food purchase. It processes an order for a Burger Meal, calculates the total cost based on the quantity ordered, identifies whether the order is for takeout, and evaluates whether the total cost meets the PHP 200.00 threshold required to qualify for free extra dips.

Variables & Operators Used

Data Types & Variables

itemName (String): Holds the name of the ordered item ('Burger Meal').

quantity (int): Stores the number of items ordered (2).

pricePerItem (double): Stores the unit price in PHP (120.0).

isTakeout (bool): Flags whether the order is for takeout (true).

totalCost (double): Stores the calculated total order cost.

qualifiesForFreeDips (bool): Stores the evaluation result for the promotional offer.

Operators Applied

Arithmetic Operator (*): Multiplies quantity by pricePerItem to compute totalCost.

Comparison Operator (>=): Compares totalCost against 200.0 to determine eligibility for free dips.
